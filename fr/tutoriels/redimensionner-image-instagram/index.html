Comment redimensionner une image pour Instagram

Créez des publications carrées ou portrait sans couper les visages, les produits ou le texte.

Préparer une image Instagram ↗

Instagram accepte plusieurs formats. Choisir le ratio avant d’ajouter du texte évite de placer des éléments importants trop près des bords.

Les formats 1:1 et 4:5 sont des points de départ simples pour le fil d’actualité.

Votre image reste sur votre appareil

Le fichier est traité dans votre navigateur. Il n’est pas envoyé vers un serveur PixEdito.

Étape par étape

Comment procéder

  1. 01

    Choisissez la forme

    Utilisez 1:1 pour un carré, 4:5 pour un portrait ou 1,91:1 pour un paysage.

  2. 02

    Cadrez le sujet

    Gardez les visages, produits et textes loin des bords extrêmes.

  3. 03

    Réglez les pixels

    Utilisez 1080×1080 pour un carré ou 1080×1350 pour un portrait 4:5.

  4. 04

    Vérifiez le texte

    Contrôlez la lisibilité à la taille d’un téléphone.

  5. 05

    Exportez

    Choisissez un JPG de qualité pour une photo ou un PNG pour un visuel avec du texte.

Conseils utiles

  • Centrez les éléments importants.
  • Évitez les réexportations répétées.

Réponses rapides

Questions fréquentes

Quelle taille pour un portrait Instagram ?

1080×1350 pixels avec un ratio 4:5 est un choix pratique.

PNG ou JPG ?

JPG convient aux photos ; PNG peut mieux préserver les visuels contenant du texte.
