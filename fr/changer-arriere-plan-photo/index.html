Méthode transparente

L’IA crée le détourage ; les calques créent le nouveau décor.

PixEdito possède une seule action IA : supprimer le fond d’un portrait. Le remplacement est ensuite réalisé avec l’éditeur classique. Vous contrôlez ainsi la couleur, l’image, la taille et la position sans relancer le modèle.

Le portrait transparent peut être posé sur un fond blanc pour une fiche, sur une couleur de marque pour une équipe ou sur une photographie pour une affiche. Le nouveau décor étant sur un calque séparé, il reste facile à déplacer ou à remplacer.

Étapes

Comment remplacer le fond

  1. 01

    Ouvrir le portrait

    Chargez la photo originale dans PixEdito.

  2. 02

    Supprimer le fond existant

    Ouvrez Supprimer le fond et attendez l’aperçu transparent.

  3. 03

    Ajouter le portrait comme calque

    Gardez le détourage au-dessus des futurs calques de fond.

  4. 04

    Créer ou importer le nouveau fond

    Ajoutez un calque rempli pour une couleur, ou importez une image sous le portrait.

  5. 05

    Composer et exporter

    Redimensionnez les calques, contrôlez les contours et enregistrez le résultat.

Composition

Conseils

  • Faites correspondre la direction de la lumière.
  • Utilisez un fond simple près des cheveux.
  • Gardez un contraste suffisant avec les vêtements.
  • Réservez de l’espace pour le texte.
FAQ

Questions sur le changement de fond

Le remplacement est-il un mode IA ?

Non. L’IA supprime seulement le fond ; le nouveau décor est créé manuellement avec les calques.

Puis-je utiliser un fond blanc ?

Oui. Ajoutez un calque blanc sous le portrait transparent.

Puis-je utiliser ma propre image ?

Oui. Importez-la, placez-la sous le portrait et adaptez-la au canevas.
