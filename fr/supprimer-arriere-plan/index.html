Une fonction précise

Détourer un portrait dans un véritable éditeur d’images.

Un suppresseur d’arrière-plan identifie le sujet au premier plan et rend transparents les pixels qui l’entourent. Le modèle actuel de PixEdito est conçu pour les personnes et les photos de portrait. Le parcours reste volontairement simple : choisissez une image, attendez le détourage, comparez l’original et le résultat transparent, puis téléchargez ou poursuivez la retouche.

Le traitement se déroule dans le navigateur. PixEdito charge le moteur MediaPipe et le modèle de portrait uniquement lorsque vous ouvrez l’outil. La photo sélectionnée est analysée sur votre appareil au lieu d’être envoyée vers un serveur PixEdito. Cette approche convient aux photos de profil, trombinoscopes, vignettes, présentations et visuels dans lesquels une personne doit être séparée du décor.

La suppression du fond est la seule fonction IA de PixEdito. Le recadrage, le redimensionnement, le texte, le dessin, les sélections, les filtres et l’export restent des outils classiques que vous contrôlez manuellement.

Étape par étape

Comment supprimer le fond d’une photo

  1. 01

    Ouvrir le suppresseur de fond

    Cliquez sur « Supprimer le fond » dans l’éditeur ou utilisez le bouton de cette page.

  2. 02

    Choisir un portrait

    Ouvrez une image JPG, PNG ou WebP. Un portrait net et bien éclairé donne généralement un contour plus propre.

  3. 03

    Attendre la suppression automatique

    PixEdito détecte la personne et crée directement le résultat transparent. Aucun autre mode IA n’est nécessaire.

  4. 04

    Vérifier le détourage

    Examinez les cheveux, les épaules, les mains et les vêtements. Le damier représente les zones transparentes.

  5. 05

    Télécharger ou ajouter un calque

    Téléchargez le PNG transparent ou ajoutez le portrait détouré comme nouveau calque dans PixEdito.

Meilleurs détourages

Conseils pour des contours plus propres

  • Utilisez une image nette et suffisamment grande.
  • Privilégiez un contraste entre les cheveux, les vêtements et le décor.
  • Gardez toute la tête et les épaules dans le cadre.
  • Évitez les groupes nombreux et le flou de mouvement.
  • Conservez l’original pour les corrections manuelles.
Réponses rapides

Questions sur le suppresseur de fond

L’outil est-il gratuit ?

Oui. Il fonctionne sans compte, abonnement ni clé API.

Ma photo est-elle téléversée ?

Non. La suppression du fond est calculée dans votre navigateur après le chargement du modèle.

Puis-je conserver la transparence ?

Oui. Téléchargez le résultat au format PNG.

Fonctionne-t-il pour les produits ou les animaux ?

Le modèle actuel vise les personnes et les portraits. Les produits, animaux, logos et groupes complexes ne sont pas garantis.
