Formats de fichier · 3 min

Comment convertir PNG, JPG et WebP en ligne

Choisissez le bon format pour les photos, la transparence et les sites rapides.

Convertir une image ↗
Publicité
Dans ce guideAperçu1. Ouvrez l’image source2. Effectuez les retouches3. Choisissez le format4. Réglez la qualité5. TéléchargezConseilsQuestions

JPG convient aux photos, PNG conserve la transparence et WebP offre souvent des fichiers plus légers pour le web.

La conversion se fait lors de l’enregistrement : ouvrez l’image puis choisissez un nouveau format.

Votre image reste sur votre appareil

Le fichier est traité dans votre navigateur. Il n’est pas envoyé vers un serveur PixEdito.

Étape par étape

Comment procéder

  1. 01

    Ouvrez l’image source

    Sélectionnez un fichier JPG, PNG ou WebP depuis votre appareil.

  2. 02

    Effectuez les retouches

    Recadrez ou redimensionnez si nécessaire, sinon passez directement à l’enregistrement.

  3. 03

    Choisissez le format

    JPG pour une photo, PNG pour la transparence ou WebP pour un fichier web compact.

  4. 04

    Réglez la qualité

    Pour JPG et WebP, réduisez légèrement la qualité si vous souhaitez un fichier plus petit.

  5. 05

    Téléchargez

    Enregistrez la nouvelle version et vérifiez le résultat avant de supprimer l’original.

Publicité
Pour un meilleur résultat

Conseils utiles

  • JPG ne conserve pas la transparence.
  • PNG est adapté aux captures d’écran.
  • WebP est efficace pour les sites modernes.
Réponses rapides

Questions fréquentes

PNG vers JPG supprime-t-il la transparence ?

Oui. Les zones transparentes deviennent un fond uni.

Quel format est le plus léger ?

WebP produit souvent des fichiers plus petits à qualité visuelle comparable.
