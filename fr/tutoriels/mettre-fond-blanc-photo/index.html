Mettre un fond blanc sur une photo gratuitement

Supprimez le décor du portrait, ajoutez le détourage comme calque et placez un fond blanc pur #FFFFFF dessous.

Un fond blanc peut rendre un portrait plus propre, plus régulier et plus facile à intégrer dans une fiche, un document ou une page d’équipe. La méthode la plus contrôlable consiste à créer d’abord un portrait transparent, puis à placer un calque blanc sous la personne.

PixEdito utilise l’IA pour une seule action : supprimer le fond d’un portrait. Le blanc est ensuite ajouté manuellement dans l’éditeur à calques. Cette séparation évite de présenter le remplacement de couleur comme une autre fonction IA et vous permet de choisir exactement le blanc, la taille et le cadrage.

La valeur hexadécimale d’un blanc pur est #FFFFFF. Pour une photo officielle, vérifiez toujours les règles de l’administration concernée : la couleur du fond, les dimensions, l’expression du visage et le cadrage peuvent varier selon le pays et le document.

Votre photo reste locale

Le détourage et les opérations de calques sont effectués dans votre navigateur. PixEdito ne téléverse pas l’image vers son propre serveur pour la traiter.

Étape par étape

Comment mettre un fond blanc sur un portrait

  1. 01

    Ouvrez le portrait dans PixEdito

    Choisissez la meilleure version du fichier. Un portrait net, bien éclairé et contrasté par rapport au décor produit généralement des contours plus propres.

  2. 02

    Supprimez l’arrière-plan

    Ouvrez l’outil Supprimer le fond et utilisez le canevas actuel. PixEdito charge le modèle local, détecte la personne et affiche le résultat transparent à côté de l’original.

  3. 03

    Ajoutez le portrait comme nouveau calque

    Cliquez sur Ajouter comme calque. Le détourage doit se trouver au-dessus des calques de fond afin que le visage, les cheveux et les vêtements restent visibles.

  4. 04

    Créez un calque blanc #FFFFFF

    Ajoutez un nouveau calque sous le portrait, remplissez-le de blanc pur et vérifiez qu’il couvre tout le canevas. La valeur #FFFFFF correspond au blanc RVB standard.

  5. 05

    Vérifiez les contours et le cadrage

    Zoomez sur les cheveux, les épaules et les mains. Repositionnez le portrait et recadrez seulement après avoir contrôlé les bords.

  6. 06

    Exportez le fichier final

    Le format JPG convient à une photo finale avec fond blanc. Le PNG convient si vous souhaitez conserver une qualité sans perte ou réutiliser la version transparente séparément.

Conseils pour un fond blanc propre

  • Utilisez un portrait net avec le visage entièrement visible.
  • Évitez une photo trop sombre ou un arrière-plan similaire aux cheveux.
  • Placez toujours le calque blanc sous le portrait transparent.
  • Utilisez #FFFFFF si un blanc pur est demandé.
  • Gardez de l’espace autour de la tête avant le recadrage final.
  • Vérifiez les exigences officielles avant d’utiliser l’image pour un document.
Pourquoi utiliser des calques

Le portrait et le fond restent indépendants

Avec deux calques, vous pouvez déplacer la personne sans modifier le blanc, changer le cadrage ou remplacer plus tard la couleur. Cette méthode est utile pour une série de portraits : le même fond peut être conservé tandis que chaque personne reste séparée.

Le fond blanc n’est pas un mode IA. L’IA se limite au détourage. Le remplacement est une opération normale et visible de l’éditeur, ce qui permet de comprendre exactement comment l’image finale est construite.

Questions fréquentes

Comment mettre un fond blanc gratuitement ?

Supprimez le fond du portrait, ajoutez le détourage comme calque, puis créez un calque blanc #FFFFFF dessous.

Le fond blanc est-il ajouté par l’IA ?

Non. L’IA supprime uniquement le fond du portrait. Le blanc est ajouté manuellement avec un calque.

Quel format faut-il utiliser ?

JPG convient à une photo finale avec fond blanc. PNG conserve mieux la qualité et permet aussi de garder une version transparente.

Cette méthode convient-elle aux photos de passeport ?

Elle peut créer un fond propre, mais vous devez vérifier les règles officielles du pays ou de l’organisme avant toute utilisation.

Faut-il créer un compte ?

Non. Le suppresseur de fond et l’éditeur fonctionnent sans compte PixEdito.
